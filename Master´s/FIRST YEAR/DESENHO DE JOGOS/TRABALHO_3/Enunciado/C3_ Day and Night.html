C3: Day and Night
Twitch, Strategy and Delivery

Challenge

In this challenge, your goal is to blend elements of strategic planning with real-time reflexes.

Start by selecting a game that relies entirely on strategy—one where chance or quick reactions play no role. Then, reimagine its rules to introduce a dynamic, twitch-based element, creating a hybrid experience that combines thoughtful decision-making with rapid execution.

Your game must use the theme "Delivery".

Design and Implement a game that:

  • Is based in a pure strategic game.
  • To which where added twitch mechanics;
  • Uses the theme "Delivery";
  • Respects the course contents

Make sure that you are following Game Design basics:

  • Think about the player's viewpoint:
    • What's this game about?
    • How do I play?
    • How do I win?
    • Why do I want to play?
    • What things do I need to do?
  • Ensure meaningful decisions:
    • Consider the player's options.
    • Choices must affect the game's outcome.
    • Look to keep the player's mind busy.
  • Apply a twitch element:
    • The twitch decisions have an obvious correct action?
    • The challenge comes from executing that action quickly and accurately?
  • Consider the core of the game: Set polished core mechanics considering the features, dynamics and the theme.

Deliverable

An archive (a zip file) with:

  • A beta prototype of the game (All systems have been implemented and all code is theoretically complete. No major bugs are expected.).
  • A concept document of the game (a pdf file) as outlined in the Concept Document Structure chapter of the course notes.

Optional Game Features

Dynamic Difficulty Adjustment

Implement a "Dynamic Difficulty Adjustment" system:

  • If the player is doing too well, the difficulty can increase until the player is sufficiently challenged.
  • If the player is losing frequently, the game can ease up a bit so that the player is not frustrated. where either the strategic decisions or the twitch mechanics are harder.

Other Features

Describe and implement other features, not listed here, that might improve the game experience.

The game has instructions? A tutorial mode? Can it be paused, saved, loaded? The player has some kind of score?

Suggested Process

  1. Choose a pure strategic game. The player experience involves making decisions that influence the game state. For example, checkers and variants, nim and variants and even tic, tac, toe and variants (in godot) or bomberman and variants (in godot), etc.
  2. Consider a goal based on the theme. What is being delivered and by whom? Choose how the theme involves some strategic and twitch actions.
  3. Choose the twitch mechanics. Pure speed?, Timming?, Precision?, Avoidance?, Time Pressure?, etc.
